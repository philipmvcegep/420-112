# Exercices

Ces exercices permettent de pratiquer les notions vues dans la section **Bases**.

## Environnement

### Exercice 1 — Ma première page

Crée un dossier pour ton projet et un fichier :

```text
index.html
```

Ouvre-le dans ton éditeur de code et dans ton navigateur.

Ajoute du texte simple dans le `<body>`, enregistre le fichier et actualise la page.

**Objectif :** comprendre la boucle :

```text
modifier → enregistrer → actualiser
```

---

## Inspecter

### Exercice 2 — Explorer une page

Ouvre une page Web de ton choix.

1. Ouvre les outils de développement avec **F12**.
2. Utilise **Inspecter** pour sélectionner différents éléments.
3. Trouve un titre, un paragraphe et un lien.
4. Observe leur HTML dans l'onglet **Éléments**.
5. Explore l'onglet **Sources** et identifie quelques fichiers utilisés par la page.

**Objectif :** faire le lien entre ce qui est affiché et le code qui le produit.

---

## Structure

### Exercice 3 — Construire une page

Crée une page HTML complète contenant :

- `<!DOCTYPE html>`
- `<html>`
- `<head>`
- `<title>`
- `<body>`

Dans le `<body>`, ajoute un message de bienvenue.

**Objectif :** reconnaître et utiliser la structure de base d'un document HTML.

---

## Styles

### Exercice 4 — Personnaliser la page

À partir de ta page précédente :

1. Change la couleur d'un texte.
2. Change la couleur de fond d'un élément.
3. Change la taille d'un texte.
4. Centre un élément.
5. Change sa police.

Utilise uniquement l'attribut `style`.

**Objectif :** expérimenter avec quelques propriétés CSS directement dans le HTML.

### Exercice 5 — Mise en forme

Ajoute à ta page :

- un retour à la ligne avec `<br>`;
- un texte en **gras** avec `<strong>`;
- un texte en *emphase* avec `<em>`;
- un texte souligné avec `<u>`;
- un texte barré avec `<s>`.

**Objectif :** utiliser différentes balises de mise en forme.

---

## Texte

### Exercice 6 — Une petite page

Crée une page sur un sujet de ton choix.

Elle doit contenir :

- un `<h1>` pour le titre principal;
- au moins deux `<h2>` pour organiser le contenu;
- au moins trois paragraphes;
- du texte en `<strong>`;
- du texte en `<em>`;
- au moins un `<br>`.

Ajoute également quelques styles avec `style=""`.

**Objectif :** combiner les notions de la section Bases.

---

## Défi — Ma première page complète

Crée une petite page de présentation personnelle.

Elle doit contenir :

- un titre principal;
- plusieurs sections;
- des paragraphes;
- différentes mises en forme;
- différentes couleurs;
- différentes tailles de texte;
- au moins un élément centré;
- au moins un changement de police.

Une fois terminée :

1. ouvre la page dans ton navigateur;
2. utilise **Inspecter**;
3. retrouve tes différents éléments dans le HTML;
4. expérimente en modifiant leurs styles directement dans les outils de développement.

> 💡 Le but n'est pas de créer une belle page. Le but est de comprendre comment le fichier HTML, l'éditeur, le navigateur et les outils de développement fonctionnent ensemble.
