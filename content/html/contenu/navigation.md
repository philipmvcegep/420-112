Un peu comme nous avions fait avec les styles, on peut définir une référence Web sur une balise HTML.

L'exemple suivant est le plus classique:

```html
<a href="https://isp.example.net/">ISP™</a>
```

La structure est toujours la suivante pour une balise: `<a attribut>texte</a>`. On définit un attribut à `<>` pour la modifier, texte sera affiché à l'écran. Visuellement, `href` sera toujours dans la balise ouvrante, comme `style` l'était.
